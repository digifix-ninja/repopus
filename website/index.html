How it works Download GitHub

Your GitHub repositories, kept on your disk and always up to date.

Paste a link to an account or a repository. Repopus checks GitHub every hour, downloads only what changed, and never deletes anything that disappears.

Download Repopus View the source

Free and open source. For macOS, Windows and Linux. All downloads

One link is all it takes

github.com/your-account

Follows every repository of the account, including new ones as they appear. Each account gets its own category.

github.com/your-account/project/tree/dev

Adds just that repository. Add /tree/branch to follow a branch other than the default.

What happens every hour

  1. Ask

    Repopus asks GitHub whether anything was pushed since the last check. An unchanged repository costs almost nothing.

  2. Compare

    The latest commit on GitHub is compared with the copy on your disk.

  3. Download

    Only repositories that changed are downloaded, a few at a time, with live progress.

  4. Swap

    The new copy is checked in a temporary folder first, then swapped in. An interrupted download never breaks the copy you have.

Every repository, one glance

  • Up to date

    Your copy matches the latest commit on GitHub.

  • Update available

    There's a newer version, or it hasn't been downloaded yet. Update one, an account, or all.

  • Needs a look

    Gone from GitHub (your copy is kept), missing on your computer, or an error to read.

Things Repopus will never do

Delete a repository because it vanished from GitHub.
It's marked as gone. Your files stay exactly where they are.
Touch files it didn't make.
It only ever replaces its own copies. Anything unknown in the way is renamed, not removed.
Talk to anyone but GitHub.
No account, no tracking, no analytics. Your token lives in your system's keychain.

Set it up the way you work

Zip or folder
Keep each repository as a zip archive or as an unpacked folder.
Replace or keep versions
One up-to-date copy, or every version side by side, named by date and commit. Keep the last few, or all of them.
Your folders
Everything goes into a Repopus folder in your home folder, or wherever you choose, per repository.
Automatic or by hand
Choose per repository whether it updates by itself. Repopus waits quietly in the menu bar or system tray.
Private repositories
Add a read-only GitHub token, or let Repopus use your GitHub CLI login.
Light or dark grey
Or simply follow your system.

Repopus is written in Rust with Tauri. The interface is plain HTML, CSS and JavaScript, with no Node.js needed. Bug reports, ideas and pull requests are welcome.
