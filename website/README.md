# repopus.app

The Repopus homepage: a static site with no build step and no external requests.

- `index.html`, `styles.css`, `site.js`
- `assets/` – logo, icons, screenshot (for link previews) and the self-hosted Poppins font

Open `index.html` in a browser to look at it, or upload the whole folder to any static host
(GitHub Pages, Netlify, Cloudflare Pages, plain web space). Download links point to
https://github.com/digifix-ninja/repopus/releases/latest.
